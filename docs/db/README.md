# データベースの構成とテーブルの役割

このプロジェクトでは、以下のテーブルがデータベースに含まれています。それぞれのテーブルは特定の目的を持ち、システム全体のデータ管理を効率化します。

## テーブル一覧

1. **action_types**
   - 行動の種類を定義するテーブルです。
   - 例: 「移動」「飲食」

2. **settings**
   - システム設定値を管理するテーブルです。
   - キーバリュー形式で便利に使用されます。

3. **user**
   - ユーザー情報を管理するためのテーブルです。

4. **target**
   - 観察対象の情報を管理するテーブルです。
   - 対象の属性を格納します。

5. **temp_actions**
   - ユーザーが入力途中の行動データを保存するためのテーブルです。
   - 後で確定処理を実施します。

6. **action_logs**
   - 観察対象の行動履歴を記録するテーブルです。
   - 傾向分析に利用されます。

7. **error_logs**
   - システムエラーや例外を記録するテーブルです。
   - トラブルシューティングに使用されます。

このREADMEは、データベースの構成を理解し、各テーブルの役割を把握するためのガイドとして利用してください。
