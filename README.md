# README

## 概要
オープンデータと生成AIを活用し、日々の記録の積み重ねから「自分専用のデータフォーマット」を設計・更新できるWebアプリ。

## 対象ユーザー等
- 対象ユーザー: 日々の行動や状態を振り返りたいユーザー
- 利用場面: ログを条件検索し、傾向を見たい場面
- 提供価値: 主観だけでなく、外部データも含めた比較観点で状況を把握しやすくする

## 活用するデータ / API
- オープンデータ: Open-Meteo（気象時系列データ）
- AI: OpenAI / Gemini 等のLLM（分析結果の自然言語説明）
- アプリ内データ: 行動ログ、タグ、保存検索条件

## 画面イメージ（簡易）
- 検索入力（AND/OR/NOT）
- 結果一覧 + 1D/2D可視化
- 外部データ（例: 気象）との重ね合わせ
- 分析結果の自然言語説明

## 技術構成（想定 / 一部実装）
- Frontend: React + TypeScript
- Backend: Go（HTTP API）
- Database: PostgreSQL
- Auth: JWT / OAuth（Google）
